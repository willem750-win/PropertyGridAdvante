# PropertyGridAdvante (propadvance)

Lazarus component `TAdvancedPropertyGrid`: a property grid that shows a chosen set of
published properties of a component, with translated property names (Dutch, English,
French, German), colour and boolean editors, and saving/loading of the values to an ini file.

Used by [Logic](https://github.com/willem750-win/Logical), a digital circuit simulator, for its settings screen.

## Requirements
Lazarus with the packages `rx`, `rxnew`, `rxtools`, `richmemopackage`, `FrameViewer09`
(HtmlViewer) and `RunTimeTypeInfoControls`; all available in the Lazarus Online Package Manager.

## Install
Open `propadvance.lpk` in Lazarus and choose *Compile* (and *Use › Install* for design time).
